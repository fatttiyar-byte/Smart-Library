# Smart-Library
A modern Smart Library web app built with React, Bootstrap, Material UI &amp; Toastify


 📚 Smart Library

A modern, responsive **Smart Library** web application built with **React**, **Bootstrap**, **Material UI**, and **React Toastify**.  
This app allows users to browse, search, and manage books in a clean and user-friendly interface.



✨ Features

- 🔍 **Search & Filter** books by title, author, or category
- 📖 **Book Details** page with full information
- ➕ **Add / Edit / Delete** books (CRUD operations)
- 🔔 **Toast Notifications** for user actions (using React Toastify)
- 🎨 **Responsive UI** with Bootstrap & Material UI
- 🌙 **Modern & Clean Design**
- ⚡ **Fast Performance** with React Hooks
- 📱 **Mobile-Friendly** layout



🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| ⚛️ React | Frontend library |
| 🅱️ Bootstrap | Responsive grid & components |
| 🎨 Material UI (MUI) | Modern UI components |
| 🔔 React Toastify | Toast notifications |
| 🧭 React Router | Page navigation |
| 🌐 Axios | API requests (optional) |
