## 📖 Overview

**Smart Library** is a front-end web application that delivers a clean, modern, and fully responsive interface for managing library resources. Built on a component-driven React architecture with Vite as the build tool, it combines Bootstrap and Material UI for a polished design system, while React Toastify provides elegant user feedback through notifications.

> ⚡ Fast, lightweight, and built for a smooth user experience.
